# FizzBuzz (1〜50) Web ページ

1から50までの数値を FizzBuzz のルールに従ってカード形式で視覚的に一覧表示する、シンプルな Web アプリケーションです。

## 概要

本プロジェクトは HTML / CSS / JavaScript のみで構築されており、外部ライブラリへの依存なしにブラウザで直接動作します。

### FizzBuzz ルール
- **3 の倍数**: `Fizz`
- **5 の倍数**: `Buzz`
- **15 の倍数 (3 と 5 の公倍数)**: `FizzBuzz`
- **それ以外**: 数値そのものを表示

---

## 主な特徴

- **単一ファイル完結**: `index.html` 内に HTML、CSS、JavaScript を内包しており、セットアップ不要ですぐに動かせます。
- **カード・グリッドデザイン**: 画面サイズに合わせて最適な列数に調整されるレスポンシブなグリッドレイアウトを採用しています。
- **直感的なカラーリング**:
  - 🟣 **FizzBuzz**: 目立つグラデーションカード
  - 🔵 **Fizz**: スカイブルー
  - 🟠 **Buzz**: アンバーオレンジ
  - ⚪ **数値**: ニュートラルカード
- **ホバーエフェクト**: 各カードに微かなホバーアニメーションを付与しています。

---

## 使い方

特別なビルドやローカルサーバーの起動は不要です。

1. 本リポジトリをクローンまたはダウンロードします。
2. `index.html` をお好みのブラウザ（Google Chrome、Edge、Safari、Firefox など）でダブルクリックして開きます。
