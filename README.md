# FizzBuzz RUSH (1〜50) 🎮

1から50までの数値を FizzBuzz のルールに従って直感的なキーボード操作で判定していく、反射神経＆タイムアタック型ゲームです！

---

## 🎮 ゲームの遊び方

画面に大きく表示される数字に対して、キーボードの対応キーを素早く押して最速タイムを目指します。

### キーボード操作一覧
| 判定 | 対応キー | 条件 |
| :--- | :--- | :--- |
| **そのまま (数値)** | **`1`** または **`Space`** (または `J`) | 3 でも 5 でも割り切れないとき |
| **Fizz** | **`2`** または **`F`** | 3 の倍数のとき |
| **Buzz** | **`3`** または **`B`** | 5 の倍数のとき |
| **FizzBuzz** | **`4`** または **`Z`** | 15 の倍数 (3と5の公倍数) のとき |

- **スタート / リトライ**: **`Space`** または **`Enter`**
- マウスクリックや画面タップでも操作可能です。

---

## ✨ 主な特徴

- **爽快な効果音 & コンボ演出**: Web Audio API によるシンセ音を搭載。連続正解でピッチが上がり、ミスすると画面がシェイクします。
- **リザルト＆ランク判定**: クリアタイム、ミス回数、最大コンボ数に応じたランク（S / A / B / C）が表示されます。
- **タブ切り替え機能**:
  - `🎮 キーボードゲーム`: タイムアタックゲーム画面
  - `📋 1〜50 一覧`: 従来の1〜50のカード一覧表示
- **完全スタンドアロン**: 外部ライブラリなし、`index.html` 1ファイルだけで軽快に動作します。

---

## 起動方法

1. `index.html` をお好みのブラウザ（Chrome, Edge, Safari, Firefox など）で直接ダブルクリックして開きます。
2. スペースキーを押してゲームスタート！
